# **paw rescue webapp**
The primary motive of PawNet is encapsulated in its core philosophy: **"Report it. Track it. Rescue it."** — *establishing a centralized, hyper-local rescue network that transforms the unorganized stray cat welfare efforts in India into a highly coordinated and gamified community ecosystem.* 

By bridging the gap between concerned citizens, active volunteers, foster homes, vets, and donors, the application acts as an end-to-end rescue pipeline that leverages to prioritize critical animal emergencies, tracks rescue timelines transparently, and ultimately works to rehabilitate and find permanent, loving homes for every street cat in need.
